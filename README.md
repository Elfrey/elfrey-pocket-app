# Elfrey Pocket App

Мобильный бланк персонажа для системы **dnd5e** в Foundry VTT (v13 / v14). Игрок открывает Foundry на телефоне и получает удобный полноэкранный бланк персонажа с бросками, инвентарём, заклинаниями и чатом — без карты, токенов и лишнего интерфейса. Все броски и действия идут через штатный движок dnd5e, поэтому мастер видит обычные карточки в чате, а автоматизация мира работает как всегда.

## Установка (мастер)

1. В Foundry: *Дополнения → Установить модуль* → вставьте manifest-URL → включите **Elfrey Pocket App** в мире.

   Manifest-URL:
   ```
   https://github.com/Elfrey/elfrey-pocket-app/releases/latest/download/module.json
   ```
2. **Только для Foundry v14** — один разовый шаг на компьютере, где запущен Foundry (v14 иначе не отдаёт страницу приложения). Повторяйте его после каждого обновления Foundry:
   - **macOS / Linux:** `sh Data/modules/elfrey-pocket-app/tools/install-v14.sh`
   - **Windows:** правый клик по PowerShell → *Запуск от имени администратора* → `.\Data\modules\elfrey-pocket-app\tools\install-v14.ps1`

   Скрипт сам найдёт папку Foundry или спросит путь к ней (та папка, где лежит `public/`). Перезапускать Foundry не нужно.

На Foundry v13 второй шаг не требуется.

## Запуск (игроки)

Откройте обычную ссылку вашего Foundry на телефоне и войдите под своим игроком — модуль сам определит телефон и откроет приложение.

- **Добавить на экран «Домой»:** меню ⋮ в приложении → и оно будет запускаться на весь экран, как отдельное приложение.
- **Нужен полный клиент** (например, на планшете): меню ⋮ → *Полный клиент*.
- Мастеров приложение никогда не перенаправляет — они всегда попадают в обычный клиент.

## Как пользоваться

Внизу — панель вкладок:

- **Обзор** — пункты здоровья (урон / исцеление / временные ПЗ), класс брони, характеристики, испытания, навыки, инструменты, состояния, утомление, концентрация, инициатива и отдых. В бою вместо инициативы появляется кнопка «Закончить ход». Сверху — переключатель преимущества/помехи, «быстрый бросок» (без диалога) и кому виден бросок.
- **Избранное** — то, что отмечено избранным на полном бланке персонажа: предметы, заклинания, навыки, ячейки заклинаний.
- **Особенности** — классовые особенности, черты, вид, предыстория; сгруппированы по типу действия.
- **Инвентарь** — предметы по категориям, экипировка и настроенность на магические предметы, контейнеры, поиск, валюта (в поле можно писать `+11` или `-11`, чтобы прибавить/потратить).
- **Заклинания** — ячейки заклинаний, подготовка заклинаний (кнопка «Подготовить» открывает полный список), фильтры (круг, школа магии, компоненты, концентрация, ритуал и т.п.).
- **Ещё** — Действия, Биография (с редактированием), Дневник и Эффекты. Здесь же, в меню ⋮ сверху — смена персонажа, *Полный бланк* (обычный бланк dnd5e), тема, диагностика и выход.

**Использование** предмета, заклинания или особенности — тап по иконке. **Тап по названию** открывает карточку с описанием и кнопками (бросок атаки, бросок урона, в чат и т.д.).

**Чат** — кнопка с облачком в шапке. Есть история, быстрый набор костей (тап по кости добавляет её в бросок, рядом — модификатор и преимущество/помеха; бросок уходит отправкой сообщения), а у карточек урона/исцеления от мастера — кнопки «Применить ко мне» / «Исцелить меня».

**Быстрый старт.** Приложение показывает бланк персонажа сразу, из памяти телефона, пока подгружается мир: вкладки листаются, описания заклинаний и предметов открываются. Пока идёт загрузка, сверху видна полоса «Данные от …», действия и броски недоступны; как только мир загрузился, бланк молча становится живым.

**Тема** (светлая / тёмная / как в системе) — меню ⋮ → раздел «Тема».

## Midi-qol и автоматизация мастера

Если в мире включён **midi-qol**, использование предметов и заклинаний из приложения выполняется **на клиенте мастера** — так их обрабатывают midi-qol и всё, что построено поверх него (DAE, Chris's Premades…): броски атаки и урона, испытания целей, применение урона, эффекты, анимации. Управляется настройкой *Использовать предметы через клиент мастера* (Авто — пока midi-qol включён). Нужны мастер в сети и модуль **socketlib**.

- **Цели.** Карты на телефоне нет, поэтому перед использованием приложение показывает список целей — только тех существ, которых **видит токен персонажа** и которые **в радиусе** действия (по правилам midi-qol: reach, дальний бросок — с пометкой, стены). Вне радиуса — за кнопкой «Показать всех видимых». Имена НИП показываются так, как их видят игроки: поддерживаются **Hide NPC Names** и **Anonymous** — скрытое имя заменяется на «Неизвестное существо» (или заданное мастером). Сцена подписывается навигационным именем.
- **Реакции.** Когда НИП атакует персонажа, у которого есть реакция (Щит, внеочередная атака…), на телефоне всплывает «Реакция!» с обратным отсчётом.
- **Испытания и проверки**, которые midi-qol просит бросить игрока, бросаются на телефоне через штатный диалог dnd5e — независимо от того, каким модулем стол обычно собирает броски (Monk's Token Bar, Flash Rolls, Epic Rolls): для игроков в приложении midi-qol возвращается к своему собственному запросу, остальные продолжают пользоваться привычным модулем.
- **Диалоги Chris's Premades**, адресованные игроку («применить особенность?», выбор цели), открываются на телефоне.

- **Круг заклинания и расходники** выбираются на телефоне — открывается обычный диалог использования dnd5e (апкаст, расход слота или зарядов, концентрация), и выбор уходит мастеру вместе с запросом.

Ограничения: область (шаблон) размещает мастер — карта есть только у него; диалоги Chris's Premades пересылаются игроку, начавшему использование, но если он не ответит за две минуты или двое кастуют одновременно — открываются у мастера; диалоги самого midi-qol (метамагия, бонусы) остаются у мастера.

## Настройки мастера

*Настройки модулей → Elfrey Pocket App*:

- **Выбрать игроков** — закрепить конкретных игроков за приложением: они попадут в него с любого устройства.
- **Отправлять телефоны в мобильное приложение** — Авто (по умолчанию) / Всегда / Никогда.
- **Адрес приложения** — определяется автоматически; менять нужно только для нестандартных схем (например, реверс-прокси).
- **Использовать предметы через клиент мастера** — Авто (по умолчанию, пока включён midi-qol) / Всегда / Никогда. См. раздел про midi-qol.
