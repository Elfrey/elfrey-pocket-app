# Elfrey Pocket App

Мобильный лист персонажа для системы **dnd5e** в Foundry VTT (v13 / v14). Игрок открывает Foundry на телефоне и получает удобный полноэкранный чарлист с бросками, инвентарём, заклинаниями и чатом — без карты, токенов и лишнего интерфейса. Все броски и действия идут через штатный движок dnd5e, поэтому мастер видит обычные карточки в чате, а автоматизация мира работает как всегда.

## Установка (мастер)

1. В Foundry: *Дополнения → Установить модуль* → вставьте manifest-URL → включите **Elfrey Pocket App** в мире.

   Manifest-URL:
   ```
   https://github.com/Elfrey/elfrey-pocket-app/releases/latest/download/module.json
   ```
2. **Только для Foundry v14** — один разовый шаг на компьютере, где запущен Foundry (v14 иначе не отдаёт страницу приложения). Повторяйте его после каждого обновления Foundry:
   - **macOS / Linux:** `sh Data/modules/elfrey-pocket-app/tools/install-v14.sh`
   - **Windows:** правый клик по PowerShell → *Запуск от имени администратора* → `.\Data\modules\elfrey-pocket-app\tools\install-v14.ps1`

   Скрипт сам найдёт папку Foundry или спросит путь к ней (та папка, где лежит `public/`). Перезапускать Foundry не нужно.

На Foundry v13 второй шаг не требуется.

## Запуск (игроки)

Откройте обычную ссылку вашего Foundry на телефоне и войдите под своим игроком — модуль сам определит телефон и откроет приложение.

- **Добавить на экран «Домой»:** меню ⋮ в приложении → и оно будет запускаться на весь экран, как отдельное приложение.
- **Нужен полный клиент** (например, на планшете): меню ⋮ → *Полный клиент*.
- Мастеров приложение никогда не перенаправляет — они всегда попадают в обычный клиент.

## Как пользоваться

Внизу — панель вкладок:

- **Обзор** — хиты (урон / лечение / временные), КД, характеристики, спасброски, навыки, инструменты, состояния, истощение, концентрация, инициатива и отдых. В бою вместо инициативы появляется кнопка «Закончить ход». Сверху — переключатель преимущества/помехи, «быстрый бросок» (без диалога) и кому виден бросок.
- **Избранное** — то, что отмечено избранным на полном листе: предметы, заклинания, навыки, слоты.
- **Особенности** — классовые умения, черты, вид, предыстория; сгруппированы по типу действия.
- **Инвентарь** — предметы по категориям, экипировка и настройка, контейнеры, поиск, валюта (в поле можно писать `+11` или `-11`, чтобы прибавить/потратить).
- **Заклинания** — ячейки, подготовка (кнопка «Подготовить» открывает полный список), фильтры (круг, школа, компоненты, концентрация, ритуал и т.п.).
- **Ещё** — Действия, Биография (с редактированием), Дневник и Эффекты. Здесь же, в меню ⋮ сверху — смена персонажа, полный лист, тема, диагностика и выход.

**Использование** предмета, заклинания или умения — тап по его иконке. **Тап по названию** открывает карточку с описанием и кнопками (атака, урон, в чат и т.д.).

**Чат** — кнопка с облачком в шапке. Есть история, быстрый набор костей (тап по кости добавляет её в бросок, рядом — модификатор и преимущество/помеха; бросок уходит отправкой сообщения), а у карточек урона/лечения от мастера — кнопки «Применить ко мне» / «Исцелить меня».

**Тема** (светлая / тёмная / как в системе) — меню ⋮ → раздел «Тема».

## Настройки мастера

*Настройки модулей → Elfrey Pocket App*:

- **Выбрать игроков** — закрепить конкретных игроков за приложением: они попадут в него с любого устройства.
- **Отправлять телефоны в мобильное приложение** — Авто (по умолчанию) / Всегда / Никогда.
- **Адрес приложения** — определяется автоматически; менять нужно только для нестандартных схем (например, реверс-прокси).
